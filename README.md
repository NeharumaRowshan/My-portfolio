# Neharuma Portfolio — HTML + Tailwind CSS

## Files

- `index.html` — complete portfolio page
- `style.css` — custom CSS for animations and advanced effects

## How to run

1. Put both files in the same folder.
2. Open `index.html` in a browser.

Tailwind CSS is loaded through the official CDN script, so you do not need to install Node.js or Tailwind for this version.

## Customize

Search `index.html` and replace:
- `Neharuma` with your preferred display name
- `your.email@example.com` with your email
- GitHub and LinkedIn links with your profiles
- Project descriptions/details with your final project information

## Sections included

1. Hero / Above the Fold
2. Selected Work
3. Advanced horizontal scrolling process section
4. Experience / Skills
5. About
6. Contact / Footer

The design follows the section flow from the supplied reference image and includes responsive behavior, sticky project cards, scroll-reveal animations, hover effects, and mobile support.
